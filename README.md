# DSJIE 个人主页（PHP 版）

黑白极简风个人主页，v25 单文件版的 PHP 移植。全部内容可通过后台增删改，无需数据库，数据存 JSON 文件，解压即用。

## 环境要求

- PHP >= 7.4（启用 SMTP TLS/SSL 时需 OpenSSL 扩展；无需 Composer 或 MySQL）
- 可写的目录权限：`data/`、`uploads/`、`files/`

## 快速部署

1. 把本目录所有文件上传到网站根目录（宝塔 / 小皮 / Apache / Nginx 均可）。
2. 浏览器打开网站首页，会自动检测并跳转到安装向导（也可直接访问 `/install.php`）：填写站点名称、联系方式和管理员账号，点「完成安装」。站点数据会自动按示例模板初始化，全部内容之后在后台编辑。
3. 前台首页：`index.php`；后台入口：`/admin/`，用向导里设置的账号登录。
4. 安装完成后建议删除 `install.php`；以后改账号请在后台「账号」页操作（再次访问安装向导会先验证当前管理员身份）。
5. 本地调试：在本目录执行 `php -S 0.0.0.0:8080`，浏览器访问 `http://localhost:8080/install.php`。

## 部署 / 升级（解压后没权限？看这里）

1. 把压缩包解压到站点根目录（覆盖旧文件）。
2. 在站点根目录执行一次：`sh fixperm.sh`
   修复规则：目录 755、文件 644、`data/`、`uploads/`、`files/` 开放写权限 777；`data/content.json` 设为 755。
  注意：755 的 content.json 只有文件属主可写——若后台保存报权限不足，说明网站进程不是属主，执行 `chown www:www data/content.json`（宝塔面板）或改用 `chmod 666 data/content.json`。
3. 压缩包本身已按 644/755 打包，正常 unzip 解压后权限直接就对；`fixperm.sh` 是兜底（面板解压、旧包、权限错乱时一条命令修好）。

## 目录结构

```
install.php        安装向导（首次部署填写站点信息与管理员账号）
index.php          前台入口（渲染全部板块）
api.php            留言板接口（发表 / 回复）
render.php         板块渲染器（上）
render2.php        板块渲染器（下）
lib.php            公共函数
config.php         配置（默认账号、上传限制）
assets/style.css   前台样式（沿用 v25 黑白极简风）
assets/extra.css   PHP 版补充样式
assets/app.js      前台交互（板块切换/灯箱/主题/留言）
admin/             后台管理（登录、CRUD、留言管理、改密码）
data/content.example.json  示例数据模板（首次安装据此初始化站点数据）
data/content.json  站点全部内容（备份这个文件 = 备份站点；每站独立，已 gitignore 不进仓库）
data/admin.json    账号（安装向导 / 后台改密码时生成）
uploads/           图库上传的图片
files/             下载区文件
fixperm.sh         权限一键修复（解压后 sh fixperm.sh）
```

## 后台功能

- 站点设置：标题、站点名、头像文字、口号、联系按钮链接、页脚、SEO 三件套、社交链接、整站配色主色、全站背景图片链接；App 下载模块可配置名称、版本、介绍、用途和安装包
- App 安装包支持上传到 `files/` 或填写下载 URL；本站文件自动显示实际大小，外链可手动填写大小
- 关于我：简介（支持 `<strong>`）、技能标签、雷达图数值
- 作品 / 随笔 / 图库 / 下载 / 动态 / 友链：完整增删改查，图库和下载支持上传文件或填写 http(s)/站内 URL
- 留言板：查看、以站长身份回复、删除留言与回复
- 前台内容变更后会自动检查并更新当前板块（约 15 秒内，无需手动刷新）
- 邮件通知：使用 SMTP；在「站点设置 → 邮件通知」填写服务器、端口、加密方式、账号、授权码和收/发件邮箱。授权码存于 `data/identity.php`，后台不回显；SMTP 客户端已包含在 `smtp_mailer.php`，无需安装额外依赖
- 账号：修改用户名和密码

## 说明与注意

- 板块顺序固定（关于→作品→随笔→图库→动态→友链→下载→留言→版权→App 下载），与前台导航一一对应。
- 删除条目只删数据记录，已上传的文件保留在 `uploads/`、`files/` 中，不会被自动删除。
- 图库图片留空时显示 DSJIE 文字占位；下载需填写文件名并上传文件或填写 URL。上传上限为 20 MB，具体还受 PHP `upload_max_filesize` 和 `post_max_size` 配置限制。
- 备份/迁移：打包整个目录即可，重点是 `data/content.json`。
- 留言有 8 秒提交频率限制，内容自动过滤 HTML 标签，前台邮箱自动打码展示。
