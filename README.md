# DSJIE 个人主页（PHP 版）

黑白极简风个人主页，v25 单文件版的 PHP 移植。全部内容可通过后台增删改，无需数据库，数据存 JSON 文件，解压即用。

## 环境要求

- PHP >= 7.4（无扩展依赖，无需 MySQL）
- 可写的目录权限：`data/`、`uploads/`、`files/`

## 快速部署

1. 把本目录所有文件上传到网站根目录（宝塔 / 小皮 / Apache / Nginx 均可）。
2. 本地调试：在本目录执行 `php -S 0.0.0.0:8080`，浏览器访问 `http://localhost:8080`。
3. 前台首页：`index.php`；后台入口：`/admin/`。
4. 首次登录账号 `dsjie`，密码 `dsjie888`——登录后请立刻在「账号」页修改密码。

## 目录结构

```
index.php          前台入口（渲染全部板块）
api.php            留言板接口（发表 / 回复）
render.php         板块渲染器（上）
render2.php        板块渲染器（下）
lib.php            公共函数
config.php         配置（默认账号、上传限制）
assets/style.css   前台样式（沿用 v25 黑白极简风）
assets/extra.css   PHP 版补充样式
assets/app.js      前台交互（板块切换/灯箱/主题/留言）
admin/             后台管理（登录、CRUD、留言管理、改密码）
data/content.json  站点全部内容（备份这个文件 = 备份站点）
data/admin.json    账号（改过密码后生成）
uploads/           图库上传的图片
files/             下载区文件
```

## 后台功能

- 站点设置：标题、站点名、头像文字、口号、联系按钮链接、页脚、SEO 三件套、4 个社交链接
- 关于我：简介（支持 `<strong>`）、技能标签、雷达图数值
- 作品 / 随笔 / 图库 / 下载 / 动态 / 友链：完整增删改查，图库和下载支持上传文件
- 留言板：查看、以站长身份回复、删除留言与回复
- 账号：修改用户名和密码

## 说明与注意

- 板块顺序固定（关于→作品→随笔→图库→下载→留言→动态→友链），与前台导航一一对应。
- 删除条目只删数据记录，已上传的文件保留在 `uploads/`、`files/` 中，不会被自动删除。
- 图库图片留空时显示 DSJIE 文字占位；下载文件留空时前台会提示「待站长上传」。
- 备份/迁移：打包整个目录即可，重点是 `data/content.json`。
- 留言有 8 秒提交频率限制，内容自动过滤 HTML 标签，前台邮箱自动打码展示。
